# BEPC Autonome CI 🇨🇮

Plateforme éducative open source et **offline-first** pour l'étude autonome du programme ivoirien, avec une première cible : **classe de 3e et préparation au BEPC**.

## Objectif

Construire une base pédagogique structurée, traçable et exploitable par une application locale : apprendre → s'entraîner → se tester → réviser → BEPC blanc → analyser ses erreurs.

## Sources de référence

Priorité aux sources institutionnelles :
- Direction de la Pédagogie et de la Formation Continue (DPFC) ;
- Ministère de l'Éducation nationale de Côte d'Ivoire ;
- Mon École à la Maison (ecole-ci.org).

Le dépôt ne vise pas à republier intégralement les contenus protégés de ces plateformes. Il structure le curriculum, référence les sources et accueille des ressources pédagogiques originales ou réutilisables légalement.

Voir `data/3e/catalogue.json`, `docs/DATA-SCHEMA.md` et `sources/SOURCES.md`.

## Statuts de vérification

- `official_verified` : vérifié dans une source institutionnelle.
- `cross_checked` : recoupé avec plusieurs sources.
- `to_verify` : donnée provisoire à contrôler avant usage pédagogique.

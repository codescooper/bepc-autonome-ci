# Roadmap

## Phase 1 — Curriculum 3e
- inventorier toutes les disciplines ;
- extraire compétences, thèmes, leçons et progression depuis les sources institutionnelles ;
- associer chaque entrée à sa provenance ;
- contrôler les divergences entre versions.

## Phase 2 — Préparation BEPC
- fiches de révision originales ;
- exercices gradués et corrections expliquées ;
- examens blancs ;
- diagnostic des lacunes.

## Phase 3 — Application locale
- PWA installable et offline ;
- profil et progression stockés localement ;
- planning quotidien adaptatif ;
- recherche et mode examen ;
- sauvegarde/export local.

## Phase 4 — Extension
Après validation de la 3e : 6e, 5e, 4e puis primaire et lycée.
